Know your algorithms

01 / FCFS

First Come, First Served

Runs processes by arrival time, preserving input order for ties.

02 / SJF

Shortest Job First

Runs the shortest available burst to completion, without preemption.

03 / SRTF

Shortest Remaining Time

Re-evaluates remaining bursts each time unit. Input order wins ties.

04 / RR

Round Robin

Rotates the ready queue by quantum; new arrivals join before requeue.

05 / PRIORITY

Priority Scheduling

Non-preemptive selection of the smallest priority number.

06 / RR + PRIORITY

Priority-Aware Round Robin

Chooses the highest-priority waiting process each slice, with queue-order ties.
